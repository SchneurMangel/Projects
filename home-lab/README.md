# IT & Cybersecurity Home Lab

A hands-on home lab I built to practice real cybersecurity and IT skills. I set up a Windows VM and a Linux VM using UTM on my MacBook Pro M3, connected them together, and worked through a series of exercises covering packet analysis, network scanning, and log analysis.

## What I Did

- **Packet Analysis** - Captured and analyzed live network traffic using tcpdump and Wireshark. Identified ICMP, DNS, ARP, and TCP traffic between the two VMs. Saved captures to .pcap files and read them back.
- **Network Scanning** - Used Nmap to discover live hosts, scan ports, detect service versions, fingerprint the OS, and save results. Learned why Windows machines are often invisible to ping sweeps and how to work around it.
- **Log Analysis** - Read and filtered Linux auth logs to identify failed login attempts and understand what brute force activity looks like compared to normal usage.
- **SIEM Queries** - Practiced Splunk queries in a separate lab exercise.

## Tools Used

Wireshark, tcpdump, Nmap, Splunk, Ubuntu 26.04, Windows, UTM, Python
